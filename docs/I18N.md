# Bangla (bn) strings

`src/i18n/strings.json` has `en` and `bn`. `useT()` returns text; `<T k="..." />` renders it.
The EN/BN toggle (Map view) is stored in `localStorage` under `abnf_lang`.

If a key has no `bn` text, English is shown with a dotted underline, `lang="en"`, and a tooltip,
and `TODO_REVIEW i18n: missing bn translation for "<key>"` is logged once to the console.
Nothing is translated silently.
